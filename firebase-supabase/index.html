О проекте

Лабораторная работа по мобильной разработке

Authspace

Веб-приложение демонстрирует авторизацию Google/GitHub, работу с Supabase и Firebase, сортировку, Realtime и разграничение доступа.

Роли

User может просматривать и добавлять записи. Admin дополнительно может их удалять. Права проверяются на серверной стороне базы.

Первый и повторный вход

При первом входе создаётся учётная запись Authentication. При последующих входах используется существующий UID, а время последнего входа обновляется.

Хранение файлов

Firebase Cloud Storage поддерживает изображения и другие файлы. Для настройки хранилища нужно проверить тариф и правила.

Apple Sign-In

Требует отдельной настройки Apple Developer, идентификаторов приложения и OAuth-параметров. В этом проекте пока не подключён.
